# 1071. Greatest Common Divisor of Strings

## <https://leetcode.com/problems/greatest-common-divisor-of-strings>

>For two strings `s` and `t`, we say "t divides s" if and only if `s = t + t + t + ... + t + t` (i.e., `t` is concatenated with itself one or more times).
>
>Given two strings `str1` and `str2`, return the largest string x such that x divides both str1 and str2.

The first thing to understand about this problem is that `str1` and `str2` are _not_ the two strings `s` and `t`. Failing to understand this will not solve this “easy” 🙄 problem.

Here is my submission: <https://leetcode.com/problems/greatest-common-divisor-of-strings/submissions/2154630910>

## the test case revealing that I do not know what `t` is 🤔

The `expected` below represents `t`:

```csharp
string str1 = "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA";
string str2 = "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA";
string expected = "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA";

$"{nameof(str1)} length: {str1.Length}; {nameof(str2)} length: {str2.Length}; {nameof(expected)} length: {expected.Length}"
```

> Output:
>
> ```
> str1 length: 360; str2 length: 640; expected length: 40
> ```

It is no accident that the length of `expected` divides the lengths of `str1` and `str2` evenly.

This is the very definition of _dividing_ as defined in this problem.

## related subjects of interest

This problem leads me to consider the general problem of finding a substring.

I was pleasantly surprised to find that the [Knuth-Morris-Pratt (KMP) algorithm](https://hackernoon.com/understanding-and-applying-the-knuth-morris-pratt-algorithm-from-string-matching-to-stream-search) addressed this general problem in the 1970s.

### the fundamental of regular expressions is the functionality that can find an _unknown_, repeating pattern

This pattern should be regarded as profoundly fundamental: `^(.+?)\1+`

```csharp
using System.Text.RegularExpressions;

string pattern = @"^(.+?)\1+";
string input = "abcabcabcabc";
Match globalMatch = Regex.Match(input, pattern);

if (!globalMatch.Success) return;

int count = Regex.Count(input, globalMatch.Groups[1].Value);

(globalMatch.Groups[1].Value, count)
```
