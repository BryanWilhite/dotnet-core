# .NET Diagnostics

The idea here is to journey through the Microsoft .NET diagnostics tutorials:

- “[Trace .NET applications with PerfCollect](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/trace-perfcollect-lttng)”
- “[Debug a memory leak](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/debug-memory-leak)”
- “[Debug high CPU usage](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/debug-highcpu)”
- “[Debug deadlock](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/debug-deadlock)”
- “[Debug ThreadPool starvation](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/debug-threadpool-starvation)”
- “[Debug a stack overflow](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/debug-stackoverflow)”

Most of the tutorials above use code from `DiagnosticScenarios` [[GitHub](https://github.com/dotnet/samples/tree/main/core/diagnostics/DiagnosticScenarios)] which I have translated to the `DiagnosticScenarios` [directory](./DiagnosticScenarios).
